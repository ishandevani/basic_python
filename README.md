# Python Practice — Conditionals, Dictionaries, File Handling

A set of small Python programs written to practise core language features.

## Topics Covered

- **Conditionals** — if, elif, else, nested conditions, comparison and logical operators
- **Dictionaries** — creating, accessing, updating, deleting keys, looping over items, nested dictionaries
- **File Handling** — creating files, writing with `write()`, reading with `read()`, using `with open()`

## Program

1. Grade Checker
Take a score as input and print the grade based on the following:
90+ : “A”
80–89 : “B”
70–79 : “C”
60–69 : “D”
Below 60 : “F”
Use a basic if / else statement to determine the grade.

```bash
pyhton Grade_Checker.py
```


2. Student Grades
Create a dictionary where the keys are student names and the values are their grades. Allow the user to:
Add a new student and grade.
Update an existing student's grade.
Print all student grades.
Use a dictionary and basic operations with if / else.
```bash
python Student_Grades.py
```


3. Write to a File
Write a program to create a text file and write some content to it, using file functions like open() and write().
```bash
python Write_to_a_File.py
```


4. Read from a File
Open the file in read mode and use file.read() to read and display its content.
```bash
python Read_from_a_File.py
```
